# Video skill mining

Needs: Video access, complete transcripts and accessible source links.

## Read complete sources

Retrieve full transcripts and expanded descriptions, enumerating all source links. A failed caption API is not proof of no transcript: inspect the visible transcript panel before marking inaccessible. Respect the requested date window.

- Valid: read the visible transcript after an API failure and label auto-generated captions.
- Invalid: summarize a video from its collapsed description.

## Synthesize for the actual goal

Collect frameworks, shared skills, tools and organization patterns. Map each candidate to a concrete user problem, adaptation and prerequisites. Produce one ranked synthesis rather than separate recaps. Distinguish a product pitch from a reusable technique.

- Valid: prioritize a source-check method that solves the stated gap.
- Invalid: return a generic list of every product mentioned.

## Ground claims and tool recommendations

Separate demonstrated results, linked source evidence and creator extrapolation. Inspect relevant vendor documentation for capability claims; preserve incomplete access as a limitation.

- Valid: cite the source for a claimed tool capability.
- Invalid: repeat a creator’s sales claim as verified fact.
