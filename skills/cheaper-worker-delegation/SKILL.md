# Cheaper worker delegation

Needs: Agent delegation tools and current model availability or cost information.

## Verify the cost and capability premise

Inspect the actual lead model and callable worker models. If no suitable cheaper worker is available, keep the work local; do not invent identifiers or promise savings.

- Valid: use a listed lower-cost worker for a bounded inventory.
- Invalid: call same-tier delegation a cost saving without evidence.

## Bound independent work

Delegate only when expected savings exceed coordination costs. Assign distinct file ownership, exact inputs, exclusions, evidence and stop conditions. Keep authority, credentials, ambiguous live state and final integration with the lead.

- Valid: one worker inventories a specified directory without edits.
- Invalid: overlapping workers change the same files without an owner.

## Verify before relying

Reopen material artifacts and independently verify claims. Report measured savings only; worker summaries are leads rather than proof.

- Valid: inspect the cited diff and rerun its relevant check.
- Invalid: claim production success from a worker summary.
